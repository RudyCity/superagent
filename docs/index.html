Core Capabilities

Designed for developers who demand full autonomous control, context precision, and terminal efficiency.

3-Tier Multi-Agent System

Master Agent orchestrates isolated Superagents in parallel Git worktrees, which spawn atomic Subagents for execution without context collision.

SSH Remote Workspaces

Connect seamlessly to remote SSH instances. Inspect system metrics, RAM, disk usage, and manage remote workspaces directly.

Context Compaction & Pinning

Smart context engineering via LLM summarization, token tracking, pruning strategies, and global cross-session message pinning.

Terminal Presets & Commands

Configure custom terminal preset workflows (`/terminal`), background processes (`/procs`), and instant shell executions (`!`).

MCP & Skill Ecosystem

Plug into Model Context Protocol (MCP) servers and install reusable skills from skills.sh to supercharge workflow automation.

t-line Desktop Integration

Integrate natively with t-line desktop app via client/server bridge mode (`--server [port]`).

Slash Commands Reference

Search through 30+ interactive slash commands built directly into Superagent CLI.

Command Category Description
/workspace (/w) Workspace Manage local & SSH remote project workspaces (list, add, use, status)
/model Config Configure tier models (master/superagent/subagent) and model presets
/login Config Add/switch AI providers (Anthropic, OpenRouter, OpenAI, Custom)
/session Session Manage conversation sessions: list, export <id>, clear --empty
/search-history (/sh) Session Semantic search conversation history across current or all workspaces
/pin Context Pin critical messages and code context across compaction cycles
/goal Agent Activate Goal Mode for long-running autonomous overnight tasks
/terminal Tools Manage & run terminal presets (`list`, `run `, `bg`, `stop`)
/worktrees (/worktree) Workspace Manage Git worktrees: list active worktrees, prune stale metadata, remove
/mcp Tools Manage Model Context Protocol servers (list, add, remove, reload)
/memory Memory Manage RMemory long-term structured memory, scenes, and personas

Quick Start

Get up and running with Superagent in under 2 minutes.

1. Clone & Install Dependencies
git clone https://github.com/RudyCity/superagent.git
cd superagent
bun install
2. Run Superagent CLI
bun run start
3. Configure AI Provider
# Inside Superagent CLI:
/login openrouter sk-or-v1-xxxxxx
/model
